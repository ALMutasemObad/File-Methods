# File Menu Application Submission

## Introduction
The File Menu Application is a console-based Java utility that showcases practical usage of the `java.nio.file` API. It presents a guided, text-based menu that enables students to explore core file-system operations—including creation, deletion, renaming, metadata inspection, directory exploration, timestamp retrieval, file sizing, and permission checks—while receiving contextual validation feedback. The latest revision further tightens input validation (including invalid path handling) and offers an opt-in recursive delete for non-empty directories to highlight safe guardrail patterns. The goal is to reinforce familiarity with safe file handling patterns and robust user interaction techniques in Java.

## Deliverables
- `src/FileMenuApp.java`: Source code implementing the interactive menu and supporting helper methods for file operations.
- `docs/sample-execution.txt`: Text transcript capturing a representative execution of the application.
- `README.md`: Updated with build instructions and usage guidance for running the application.
